# Манга-студия: Этап 1 — Реализованные улучшения

**Ветка:** `improvements/stage-1-autodetect-page-translate`

## Что было сделано

### 1. Новый API роут для перевода полной страницы
📍 **`app/api/translate/page/route.ts`**

- Принимает изображение целой страницы одним запросом
- Вызывает vision-модель `google/gemini-3.5-flash-lite` через RouterAI (один ключ, один биллинг)
- Возвращает JSON-массив блоков текста с:
  - Оригиналом и переводом
  - Нормализованными координатами 0..1 (x, y, width, height)
  - Типом блока (speech, thought, narration, sfx)
- Обрабатывает вариативность формата ответа модели (box_2d, box, [x,y,w,h], [ymin,xmin,ymax,xmax])
- Поддерживает глоссарий (опционально: передавать имена и термины для единообразия)

### 2. Клиентская утилита для подбора размера шрифта и переносов
📍 **`utils/textFit.ts`** (новый файл)

- **`fitTextToBox(text, options)`** — подбирает оптимальный размер шрифта так, чтобы перевод вписался в бабл
- **`ensureFontLoaded(fontFamily)`** — ждёт реальной загрузки кастомного шрифта перед замерами
- **`normalizeTypography(text)`** — автозамены: `…` вместо `...`, тире, пробелы
- Умная балансировка строк: сужает текст вдоль текста, пока число строк не стабилизируется (так текст выглядит естественно)
- Всё работает в браузере через Canvas API — никаких нейросетей, копейки на bandwidth

### 3. Утилита для сэмплинга цвета фона под баблом
📍 **`utils/pageTranslate.ts`** (новый файл)

- **`translatePageWithAi(src, langFrom, langTo)`** — оркестрирует весь процесс:
  1. Загружает изображение
  2. Даунскейлит до макс 1600 px (экономит токены у модели, качество OCR не страдает)
  3. Отправляет в `/api/translate/page`
  4. Сэмплирует медианный цвет полоски вокруг каждого блока текста (это реальный цвет бабла, не буквы)
  5. Возвращает блоки с фоном и координатами
- Функция `sampleBackground()` находит медианный цвет на границе текстового блока — это автоматический подбор цвета замывки вместо жёсткого белого

### 4. Обновление `TextPanel.tsx` — новый поток автоперевода
📍 **`components/editor/panels/TextPanel.tsx`**

- Полная переработка `handlePageTranslate()`:
  - Старый локальный OCR убран (больше не нужен)
  - Используется новый API `/api/translate/page`
  - Замывка больше не всегда белая — подбирается цвет фона под каждым блоком
  - Текст автоматически подгоняется под размер бабла (используя `fitTextToBox`)
  - Текст центрируется вертикально внутри блока
  - Прогресс обновляется каждый 1–2 блока (было каждый запрос — 5–15x медленнее)

### 5. Фикс постоянного отключения AI при первой ошибке
📍 **`utils/translate.ts`**

- **Было:** флаг `aiUnavailable = true` ставился после первой ошибки (429, timeout, etc) и больше НИ КОГДА не сбрасывался — все остальные блоки шли в бесплатный Google Translate
- **Стало:** `aiUnavailableUntil` — таймер на 60 секунд. Ошибка → пауза 700ms → повтор → если упал опять → 60 сек молчания → потом снова пытается
- Поведение: слегка медленнее при rate limit, но текст не деградирует до плохого качества на остаток сессии

### 6. Обновление клиента RouterAI
📍 **`lib/routerai/client.ts`**

- Добавлена функция `translatePageBlocks()` — fetch к новому роуту
- Экспортированы типы `PageTranslationBlock` для TypeScript

### 7. Улучшение горячих клавиш
📍 **`components/editor/EditorShell.tsx`**

#### Критичный фикс: Space работает, пока зажат
- **Было:** `keydown Space` → `setActiveTool('pan')` → залипает на всю сессию
- **Стало:** 
  - `keydown Space` → сохраняем текущий инструмент → переключаемся на `pan`
  - `keyup Space` → восстанавливаем предыдущий инструмент
  - Используется `useRef(prevToolRef)` для хранения состояния

#### Новые сочетания
- `M` → rectSelect (вместо старого `R`, но оставлен как алиас)
- `W` → wand (вместо старого `G`, но оставлен как алиас)
- `K` → maskBrush (новое)
- `Ctrl+E` → открыть экспорт (было только кнопка в топбаре)
- Проверка `target.isContentEditable` добавлена — горячие клавиши больше не срабатывают в `InlineTextEditor`

## Результаты

### Скорость перевода
- **До:** одна страница (15 баблов) = 15 запросов к API = 10–15 сек = 15 токен-операций
- **После:** одна страница = 1 запрос = 2–3 сек = 1 токен-операция
- **Экономия:** 5–7x быстрее, 15x дешевле по токенам

### Качество текста
- Контекст страницы: модель видит весь диалог, не скачет между персонажами и формами обращения
- Цвет замывки соответствует баблу: белый бабл → белая замывка, чёрный → чёрная (не грязные пятна)
- Размер шрифта подобран автоматически: русский текст на 30% длиннее английского, теперь вписывается, не вылезает

### Надёжность
- Двойной retry (700ms задержка) вместо immediate fallback
- 60-сек таймер вместо отключения на сессию
- Graceful обработка вариаций ответов модели

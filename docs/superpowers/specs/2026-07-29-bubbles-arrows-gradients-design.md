# Спецификация: расширенные баблы, указатели, градиенты и неон

Дата: 2026-07-29
Статус: визуальные решения делегированы пользователем, ожидает ревью спеки

## Цель

Расширить библиотеку декоративных объектов редактора:

- добавить новые формы баблов и указателей;
- дать им сплошную, градиентную и неоновую окраску;
- позволить сохранять собственные градиенты как пресеты;
- сохранить привычную работу объектов: выбор, перемещение, независимое
  растягивание по ширине и высоте, поворот, порядок слоёв, undo/redo и экспорт.

API, AI-маршруты и серверная часть в эту задачу не входят.

## Рассмотренные подходы

### A. Только готовые визуальные пресеты

Каждая карточка создаёт текущий `BubbleObject` или `ShapeObject` с заранее
подобранными цветами и эффектами.

Плюсы: минимальный объём изменений.
Минусы: пользователь не сможет полноценно редактировать градиент, а количество
вариантов быстро раздует панель.

### B. Общая система стилей для баблов и фигур — выбран

Существующие объекты получают необязательные `fillStyle`, `strokeStyle` и
`glow`. Формы остаются в своих текущих коллекциях и автоматически используют
существующие слои, трансформации и историю.

Плюсы: единый редактор цвета, одинаковый вид на канве и в экспорте,
совместимость со старыми документами, возможность сохранять любые градиенты.
Минусы: требуется общий рендерер стилей для Konva и Canvas 2D.

### C. Библиотека независимых SVG-стикеров

Все баблы и стрелки хранятся как готовые SVG.

Плюсы: почти неограниченная внешняя сложность.
Минусы: трудно менять форму, хвост бабла и отдельные цвета; выше риск
расхождения превью и экспорта.

## Набор объектов

### Баблы

Сохраняются текущие пять:

1. Речь.
2. Мысль.
3. Крик.
4. Шёпот.
5. Нарратив.

Добавляются ещё пять:

6. Мягкий — плавная superellipse-форма.
7. Облако — крупные округлые лепестки.
8. Комикс — прямоугольный бабл со скруглением и хвостом.
9. Электро — неровный угловатый контур, подходящий для неона.
10. Титр — слегка скошенная панель для ремарок и подписей.

Все формы, кроме нарратива и титра, поддерживают хвост. Текущий
перетаскиваемый кончик хвоста и восемь пресетов направления сохраняются.

### Стрелки и указатели

В секции «Вставка» появляется отдельная галерея «Стрелки и указатели»:

1. Прямая стрелка.
2. Двойная стрелка.
3. Изогнутая стрелка.
4. Угловая стрелка.
5. Блочная стрелка.
6. Шеврон.
7. Треугольный указатель.

Для линии и стрелок добавляются варианты линии: сплошная, пунктирная и
точечная. У изогнутой стрелки при выделении показывается дополнительная ручка
изгиба; её перетаскивание меняет кривизну и создаёт одну запись undo на весь
drag.

## Трансформации и взаимодействие

- Все новые элементы создаются в центре видимой области и сразу выделяются.
- Перетаскивание двигает объект целиком.
- Восемь ручек Transformer позволяют независимо менять ширину и высоту;
  `keepRatio=false`.
- Отдельная ручка вращает объект.
- Минимальный размер защищает объект от схлопывания, но не навязывает
  пропорции.
- Все изменения одного drag/resize/rotate создают одну запись истории.
- Бабл двигает форму, хвост, свечение и встроенный текст как единый объект.
- Объекты участвуют в текущем `layerOrder`, панели «Объекты», видимости,
  дублировании и удалении по существующим правилам.

Для `ShapeObject` трансформация продолжает храниться через `x`, `y`,
`width`, `height`, `scaleX`, `scaleY`, `rotation`. После завершения ресайза
масштаб запекается в размеры там, где это нужно для стабильной толщины
обводки и свечения.

## Общая модель цвета

Добавляются совместимые типы:

```ts
interface GradientStop {
  id: string;
  offset: number; // 0..1
  color: string;
}

type PaintStyle =
  | {
      type: 'solid';
      color: string;
    }
  | {
      type: 'linear';
      angle: number; // градусы в локальных координатах объекта
      stops: GradientStop[];
    }
  | {
      type: 'radial';
      centerX: number; // 0..1
      centerY: number; // 0..1
      radius: number;  // 0.05..2
      stops: GradientStop[];
    };

interface GlowStyle {
  enabled: boolean;
  color: string;
  blur: number;      // px документа
  opacity: number;   // 0..1
  intensity: number; // 1..3 прохода свечения
}
```

В `BubbleObject` и `ShapeObject`:

```ts
fillStyle?: PaintStyle;
strokeStyle?: PaintStyle;
glow?: GlowStyle;
lineStyle?: 'solid' | 'dashed' | 'dotted'; // ShapeObject
curve?: number; // ShapeObject, только изогнутая стрелка
```

Существующие `fill` и `stroke` не удаляются. Если нового стиля нет, рендерер
строит `solid` из старого строкового цвета. Поэтому старые документы,
clipboard-фрагменты и текущие шаблоны продолжают открываться без миграции.

Градиент привязан к локальным границам объекта: при перемещении он движется
вместе с объектом, при растягивании корректно растягивается, при повороте
поворачивается вместе с объектом.

## Неоновый эффект

Неон — редактируемое свечение поверх обычной заливки/обводки, а не отдельный
тип объекта:

- переключатель «Неон»;
- цвет свечения;
- размытие;
- яркость/интенсивность;
- быстрые пресеты: голубой, розовый, фиолетовый, зелёный, золотой.

На канве используются тени Konva и, при высокой интенсивности, несколько
проходов контура. В экспорте выполняются те же проходы Canvas 2D с
соответствующими `shadowColor`, `shadowBlur` и `globalAlpha`. Свечение не
участвует в hit-test, поэтому объект выбирается по своей видимой геометрии,
а не по размытому ореолу.

## Редактор градиента

Создаётся общий компонент `PaintEditor`, используемый панелями баблов и
фигур:

- режимы «Цвет», «Линейный», «Радиальный»;
- полоса градиента с draggable-точками;
- добавление точки кликом;
- изменение цвета выбранной точки;
- удаление точки, если их больше двух;
- разворот цветов;
- угол линейного градиента;
- положение центра и радиус радиального градиента;
- живое применение к выбранному объекту;
- готовые наборы: манга, закат, океан, конфета, огонь, киберпанк и золото.

Частые движения точки или слайдера обновляют превью без истории; одна запись
undo создаётся при завершении жеста.

Заливка бабла и заливка фигуры поддерживают solid/linear/radial. Обводка и
стрелки поддерживают solid/linear; если к радиальному пресету применяется
обводка, он безопасно преобразуется в линейный по текущему углу. Цвет текста
внутри бабла в этой версии остаётся сплошным.

## Сохранение градиентов

В редакторе градиента есть кнопка «Сохранить градиент»:

- пользователь задаёт имя;
- пресет появляется в блоке «Мои градиенты»;
- пользовательские пресеты можно применить, переименовать и удалить;
- встроенные пресеты нельзя удалить;
- повторное имя не перезаписывает пресет молча, а получает суффикс;
- сохраняется копия стиля, дальнейшее редактирование объекта не меняет
  сохранённый пресет.

Пресеты хранятся локально в браузере под версионированным ключом
`manga-studio:paint-presets:v1`. Это делает их доступными после перезагрузки
и во всех документах на этом устройстве. Сам `PaintStyle` хранится внутри
объекта документа, поэтому уже применённый градиент не зависит от наличия
пресета и корректно экспортируется.

Повреждённые записи localStorage игнорируются; встроенные пресеты и редактор
продолжают работать.

## Геометрия и единый рендер

`utils/bubbleGeometry.ts` остаётся единственным источником контуров баблов и
расширяется новыми `BubbleKind`.

Для указателей создаётся `utils/shapeGeometry.ts`, возвращающий локальный
SVG path/точки для превью и экспорта. Одинаковые функции геометрии
используются в:

- мини-превью галереи;
- `ShapeNode`/`BubbleNode` на Konva-сцене;
- PNG/JPEG/ZIP-экспорте.

`utils/objectPaint.ts` становится общим источником стилей:

- нормализация и валидация stop-ов;
- вычисление локальных координат градиента;
- Konva props для preview;
- создание `CanvasGradient` для экспорта;
- проходы неонового свечения.

Так контуры, направления градиента, прозрачность и свечение совпадают на
канве и в экспортированном файле.

## Панели и удобство

### «Баблы»

- Галерея разбивается на «Классические» и «Декоративные».
- Карточка создаёт бабл, если ничего не выбрано, или меняет форму выбранного
  бабла с сохранением текста и стиля.
- Ниже находятся «Заливка», «Обводка», «Неон», «Мои градиенты», текст и хвост.

### «Вставка»

- Текущие базовые фигуры сохраняются.
- Ниже появляется отдельная визуальная галерея стрелок и указателей.
- Если выбрана фигура/стрелка, панель редактирует именно её.
- Если ничего не выбрано, параметры становятся настройками следующего
  создаваемого объекта.

Быстрые цветовые карточки сразу применяют целый стиль, но все его параметры
после этого остаются редактируемыми.

## Store, история и миграция

- `ShapeSettings` получает `fillStyle`, `strokeStyle`, `glow`, `lineStyle`.
- `addShape`/`addBubble` сохраняют полные стили в новом объекте.
- `updateShape`/`updateBubble` продолжают использовать существующую историю.
- Снапшоты истории глубоко копируют `PaintStyle.stops` и `GlowStyle`, чтобы
  изменения градиента не мутировали прошлые состояния.
- `sanitizeShape` и `sanitizeBubble` валидируют числовые поля, сортируют
  stop-ы, ограничивают offset диапазоном `0..1` и восстанавливают solid из
  legacy `fill`/`stroke` при некорректном стиле.
- Clipboard-копирование объектов переносит применённый стиль, но не всю
  пользовательскую библиотеку пресетов.

## Ошибки и крайние случаи

- У градиента всегда минимум две точки; совпадающие offset слегка разводятся.
- Пустая заливка сохраняет прозрачность и не заменяется белой.
- Нулевой stroke отключает обводку и соответствующий glow-проход.
- Очень сильное свечение ограничивается безопасным blur, чтобы не замедлять
  холст и не раздувать экспорт.
- При очень маленьком объекте толщина обводки ограничивается относительно его
  размеров.
- Неизвестный `kind` из повреждённого документа не ломает сцену: объект
  пропускается или безопасно переводится в ближайший базовый вид.

## Проверка

1. Каждый из 10 баблов и 7 указателей создаётся и сразу выделяется.
2. Каждый объект двигается, вращается, сжимается и растягивается независимо
   по ширине/высоте.
3. Хвост бабла и ручка кривизны стрелки работают и дают по одной undo-записи.
4. Сплошная, линейная и радиальная заливки совпадают на канве и в PNG/JPEG.
5. Неоновое свечение совпадает по цвету, направлению и примерной интенсивности
   на канве и в экспорте.
6. Пользовательский градиент сохраняется, остаётся после перезагрузки,
   применяется к другому объекту, переименовывается и удаляется.
7. Старый документ без новых полей открывается и выглядит как раньше.
8. Копирование/вставка, дублирование, порядок слоёв, скрытие и удаление
   сохраняют стили.
9. Один drag/resize/gradient-edit создаёт одну запись undo; Ctrl+Z возвращает
   исходное состояние.
10. Длинная работа с gradient stop и изменение размеров не вызывает
    заметного падения частоты кадров.
11. `npm run lint`, отдельный `npx tsc --noEmit` и `npm run build` проходят.
12. Выполняется браузерный smoke: создание, трансформации, сохранение пресета,
    перезагрузка и экспорт.

## Вне текущего объёма

- синхронизация пользовательских пресетов между устройствами;
- градиентный текст;
- импорт произвольных SVG-стикеров;
- перспективная деформация векторных объектов;
- изменения API и AI-маршрутов.
